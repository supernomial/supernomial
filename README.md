# Supernomial

The marketplace for Supernomial's transfer pricing agents.

## Install

In Claude Cowork: Customize, Plugins, Add, add a marketplace, enter `supernomial/supernomial`, then add the Supernomial plugin. The first time you use it, sign in with your work account. Your firm's access is set up by Supernomial.

The plugin carries only a front door; the agents' instructions are served by Supernomial after you sign in.
