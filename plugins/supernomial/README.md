# Supernomial

Supernomial's transfer pricing agents for your team: a lead agent that runs your transfer pricing work and calls on specialist teams for documentation, benchmarking, Pillar Two, disputes and more.

## Getting started

Ask anything about your transfer pricing work in a new chat. The first time, you are asked to sign in with your work account (Microsoft, Google or an e-mail code). Your firm's access is set up by Supernomial.

## What the labels mean

- **Can send data to other services:** the plugin connects to Supernomial's server to fetch its instructions and your firm's materials after you sign in.
- **Can run code without asking:** a small script on your computer tells the agent the local time and how full the chat is, so it can save its notes in time. It sends nothing anywhere.

Your work stays in the folder you choose on your own drive. Supernomial does not receive your files.

## Install

In Claude Cowork: Customize, Plugins, Add marketplace, enter `supernomial/supernomial`, then install Supernomial. In Claude Code:

    /plugin install supernomial --marketplace supernomial/supernomial
